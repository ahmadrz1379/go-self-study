## 🛠️ How to Use
1. Clone the repository:  
   `git clone https://github.com/ahmadrz1379/go-self-study.git`
2. Navigate to a topic folder.
3. Run any Go file:  
   `go run main.go`
4. Run tests (where applicable):  
   `go test ./...`
